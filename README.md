## What I build

My work sits around **AI companions, Android apps, privacy-focused communication, backend systems, automation and experimental interfaces**. I care about making projects feel complete, not just getting a demo to run once.

Right now most of my work is connected to **Kitty Corp**, where I experiment with useful AI products and unconventional software ideas.

## Featured work

| Project | What it is | Stack |
| --- | --- | --- |
| **[KITTY AI v2](https://github.com/psychspy7/KITTY.AI-v2)** | Native Android AI companion with streaming chat, voice, memory, authentication and a Cloudflare backend. | Kotlin, Jetpack Compose, Cloudflare Workers, D1, Firebase |

I learn by building. Most projects start with a question, turn into a prototype, break a few times, and eventually become something much more serious than the original idea.

I prefer shipping real systems, testing the uncomfortable edge cases, and improving them version by version.
